## Table S3 — Full Differential Expression Results (Discovery Cohort)

**File location:** `results/tables/DEG_full_TCGA.csv`  
**Format:** CSV, 23,429 genes × 10 columns  
**Comparison:** Tumor (n=647) vs Normal (n=51), TCGA-COAD + TCGA-READ  
**Method:** DESeq2 (Wald test, BH-adjusted p-values)  

### Column Description

| Column | Type | Description |
|---|---|---|
| gene_id | character | ENSEMBL gene ID with version suffix |
| gene_name | character | Gene symbol (from original featureCounts) |
| baseMean | numeric | Mean normalized count across all samples |
| log2FoldChange | numeric | Log2 fold change (tumor / normal) |
| lfcSE | numeric | Standard error of log2 fold change |
| stat | numeric | Wald test statistic |
| pvalue | numeric | Raw p-value |
| padj | numeric | BH-adjusted p-value |
| significant | logical | TRUE if padj < 0.05 AND |log2FC| > 1 |
| direction | character | "Up", "Down", or "NS" |
